# Web Comments 1.6 preview

This build contains the opt-in in-page Chrome conversation card from [pull request 2](https://github.com/eambutu/web-comments/pull/2).

1. [Download the extension ZIP](https://raw.githubusercontent.com/eambutu/web-comments/preview/in-page-comments-1.6/preview/web-comments-chrome.zip) and extract it.
2. In Chrome, open `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select the folder containing `manifest.json`. To update an existing unpacked installation, replace the files in its folder and click **Reload**.
3. Refresh the article tab. Right-click the Web Comments toolbar icon and choose **Use in-page comments**. Select a passage and click **+ Comment**.
